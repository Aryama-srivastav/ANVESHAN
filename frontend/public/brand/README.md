# Brand assets — upload your two images here (exact names matter)

Upload on GitHub into THIS folder:

  ANVESHAN/frontend/public/brand/icon.png   <- your logo (sidebar, login, favicon)
  ANVESHAN/frontend/public/brand/bg.png     <- your app background

Rules:
- Names must be lowercase exactly: `icon.png` and `bg.png`
- PNG recommended (JPG also works if you keep the .png name? No — keep PNG).
- No code change needed after upload: the app auto-detects the files.
  If a file is missing, the app silently falls back to the built-in
  Shield icon (logo) and the default dark background — nothing breaks.

Preview locally: drop the files here and restart `npm run dev`.
