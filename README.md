# Anveshan

Anveshan is a secure digital document management and verification application for investigation, legal, forensic, and governance workflows.

## Project overview

This project provides a React + TypeScript + Vite interface for managing cases, documents, uploads, verification checks, audit trails, and permissioned ledger activity.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Linting

```bash
npm run lint
```

## Notes

- Secure document intake and fingerprinting flows are included in the demo experience.
- The interface is designed for evidentiary workflows and permissioned access control.
- The application is branded as Anveshan throughout the user-facing experience.
