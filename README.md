# ANVESHAN

**Reconstruct the Evidence. Trace the Truth.**

ANVESHAN is a secure evidence intelligence and investigation platform inspired by the Smart India Hackathon 2026 problem statement:

**SIH26090 — Secure Digital Document Management System for Legal and Investigation Documents**

This repository is currently initialized with project foundations for engineering, security, and contribution workflows.

## Guiding principles

- Security-first
- Evidence-centric rather than document-centric
- Privacy by design
- Least privilege
- Evidence integrity before AI intelligence
- Human investigator remains the decision-maker
- AI must be grounded in evidence
- No real sensitive investigation data in development

## Repository foundations

- `LICENSE` — Apache License 2.0
- `.gitignore` — baseline ignores for Python, Node.js/React/Next.js, Docker, and local sensitive artifacts
- `SECURITY.md` — vulnerability reporting and sensitive-data handling policy
- `CONTRIBUTING.md` — contribution workflow and expectations
- `.env.example` — safe placeholder environment configuration
- `docs/README.md` — documentation index placeholder
